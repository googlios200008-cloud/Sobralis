# Android: предварительная автономная сборка

Эта сборка — **ранний технический прототип**, не готовое приложение для публичного запуска. Она содержит исходный интерфейс с пуделем, локальные сообщества, отдельные семейные графики и импорт/экспорт локальной копии. При первом запуске создаётся пример с вымышленными людьми. Совместный режим и аккаунты в этом APK **отключены**: интернет-разрешение не запрошено и подключить к нему существующий демосервер нельзя. Серверная версия проекта остаётся отдельной.

Локальные данные Android-приложения не являются данными браузера или серверного стенда. Они сохраняются в WebView этого приложения, не переносятся автоматически и могут быть потеряны при удалении приложения, очистке его данных или поломке устройства. Перед такими действиями экспортировать JSON вручную; JSON не зашифрован и может содержать чувствительные сведения. Восстановление заменяет локальные данные приложения после подтверждения, а не объединяет их. Автоматический Android backup отключён. Установка обновления возможна только с тем же package ID и ключом подписи; потеря ключа или установка сборки с другим ключом не должна решаться удалением приложения без предварительного резервного копирования.

## Техническая конструкция

- `ru.sobralis.app`, minSdk 23, targetSdk 35. Пользователь сообщил, что первая автономная сборка установилась и запустилась на его Android. Модель устройства и версия ОС неизвестны; подробная проверка функций, минимальной версии, поворота, системного выбора файла, клавиатуры, TalkBack и других версий WebView ещё не проводилась. Эмулятор не запускался. Указание minSdk не является гарантией совместимости.
- Собственные файлы загружаются под фиксированным HTTPS-origin `appassets.androidplatform.net` с точным allowlist из assets, без `file://`. Все прочие запросы блокируются; приложение не имеет разрешения `INTERNET`. `allowFileAccess`, mixed content и автоматические новые окна выключены. JS-интерфейс ограничен сохранением JSON через системный диалог; внутри нет сетевого или произвольного файлового API. CSP запрещает inline-скрипты, локальные обработчики заменены диспетчером; inline-стили пока разрешены. Проверки в Chromium не доказывают безопасность от XSS или работу реального WebView. Кэш собственных ресурсов отключён, но обновление с сохранением данных на реальном устройстве ещё не проверено.
- Android обрабатывает кнопку «Назад», обычные confirm/alert, выбор JSON через системный `ACTION_OPEN_DOCUMENT` и сохранение через `ACTION_CREATE_DOCUMENT`. В случае отмены файл не сохраняется. Экспорт ограничен 3 МБ; импорт дополнительно проходит существующую валидацию.
- Тестовая сборка использует собственный приватный ключ подписи, **не релизный**. При проверочной повторной сборке сертификат совпал с установленной первой сборкой; перед выдачей обновления нужно увеличить `versionCode` и проверить обновление с сохранением данных. Не публиковать ключ и пароль, не помещать их в git; хранить вместе в защищённом месте для обновлений. Автоматической защищённой копии ключа нет.

## Сборка

Нужны JDK 17, Android SDK Platform 35, Build Tools 35.0.0, Python 3 и OpenSSL. Инструменты для проверки были загружены с Android SDK repository, версии архивов platform-35_r02 и build-tools_r35_linux проверены по SHA-1 из официального репозитория. Сценарий использует `aapt`, `javac`, `d8`, `zipalign`, `apksigner`, а не Gradle. Он не собирает сервер, не запрашивает ключи в репозиторий и не удаляет пользовательские данные.

```sh
export JAVA_HOME=/path/to/jdk17
export ANDROID_SDK_ROOT=/path/to/android-sdk
scripts/build-android-offline.sh /absolute/path/sobralis-offline-test.apk
```

Первый запуск создаёт приватный `~/sobralis-private-android/offline-test.keystore` и `offline-test.pass` с правами 600; каталог имеет права 700. При наличии только одного из них сборка останавливается, а не создаёт новую пару. Можно задать `SOBRALIS_ANDROID_PRIVATE_DIR`. Не используйте этот ключ как релизный. При потере всего каталога новый ключ будет создан заново и не сможет обновить уже установленный APK.

Проверки на текущем этапе: компиляция, подписи v1/v2/v3, свойства манифеста, совпадение упакованных ресурсов, браузерный тест файлов APK с имитацией Android-интерфейса сохранения. Браузерный тест не заменяет тест системного диалога или запуска на Android. В среде разработки нет `/dev/kvm`, а доступной памяти недостаточно для безопасного запуска Android 35 в программной эмуляции одновременно с работающим стендом. Отдельно пользователь подтвердил установку и запуск предыдущей сборки на своём устройстве; полный ручной тест пока отложен.

## Эксперимент с совместным режимом

Подготовлена отдельная синтетическая сборка для архитектурной проверки подключения через второй WebView. Она не является обновлением, готовым к установке пользователем; фактический Android, HTTPS, логин и перенос данных между версиями не проверены. Сборка ограничена адресами `.test` и не подключена к реальному серверу. Подробности и ограничения: `android-connected-test.md`. Описанный выше автономный вариант по умолчанию по-прежнему не запрашивает интернет.

## До полноценного APK

Нужны защищённое подключение к реальному серверу с полноценной авторизацией и политикой ссылок, настоящая регистрация и восстановление доступа, работающие приглашения и безопасный перенос/синхронизация данных без молчаливого объединения, тесты Android на нескольких версиях и устройствах, доступность, production-подпись и процесс обновлений. Также остаются серверные ограничения и юридические задачи из `android-privacy-release.md`. Никогда не встраивать в APK демо-пароли или предварительно загруженные токены сессий.

Изменения CSP, версий ресурсов и запрета кэширования не проверены как обновление установленного APK на реальном устройстве. Не заменять установленный пользователем прототип без отдельного испытания того же package ID и подписи и заранее сохранённой локальной копии. При переходе приложение должно получать согласованные HTML и JS, иначе обработчики могут не работать.

Для некоторых нечитаемых состояний локального хранилища подготовлен [аварийный экран](local-storage-recovery.md). Его файл не зашифрован и не импортируется обычным способом; системное сохранение ограничено 3 МиБ и ещё не проверено на настоящем устройстве.
